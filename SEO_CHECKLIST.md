# Karamchari News SEO checklist

## Completed in the site

- [x] Canonical domain configured as `https://www.karamcharinews.in`
- [x] Dynamic `robots.txt` blocks admin routes and declares the sitemap
- [x] Dynamic `sitemap.xml` includes public pages, categories, and published Neon articles
- [x] Per-article titles, descriptions, canonical URLs, Open Graph metadata, and `NewsArticle` structured data
- [x] Per-category metadata and canonical URLs
- [x] Published/updated dates and editorial byline on articles
- [x] Editorial policy and correction contact page

## Required account tasks

- [ ] Deploy the latest `master` branch to Vercel.
- [ ] Open `https://www.karamcharinews.in/robots.txt` and `https://www.karamcharinews.in/sitemap.xml` after deployment.
- [ ] Create a Google Search Console **Domain** property for `karamcharinews.in` and verify it using the DNS TXT record Google provides.
- [ ] Submit `https://www.karamcharinews.in/sitemap.xml` in Google Search Console.
- [ ] Inspect the homepage and the five highest-priority article URLs; request indexing only after verifying the live content.
- [ ] Add the site to Bing Webmaster Tools and submit the same sitemap.
- [ ] Review Search Console indexing, performance, Core Web Vitals, and manual-actions reports every week.

## Publishing checklist for every news article

- [ ] Write one precise Hindi headline that matches the reader's actual question.
- [ ] Include the order/circular number, affected employees, effective date, and a plain-language summary.
- [ ] Link directly to the original government order or department page.
- [ ] State clearly whether a figure is official, proposed, estimated, or disputed.
- [ ] Add an original image or document screenshot when rights permit; use descriptive alt text.
- [ ] Link to at least two relevant internal articles or category pages.
- [ ] Review and update the article when the official position changes.
- [ ] Publish only material checked against a primary source; do not publish rumours as confirmation.

## First content clusters to build

- [ ] Rajasthan DA: latest order, calculation, arrears, rate history, and FAQ-style explainer.
- [ ] 8th Pay Commission: official updates, fitment-factor explanation, salary calculator, and myth-vs-confirmed guide.
- [ ] ACP/MACP: eligibility, service years, documents, and official-rule explainer.
- [ ] GPF/NPS: interest rate, withdrawal, nomination, annual statement, and scheme comparison.
- [ ] DPC and promotion: process, record checklist, seniority, review DPC, and orders.
- [ ] Pension: family pension, gratuity, commutation, retirement checklist, and official updates.

## Quality guardrails

- [ ] Do not buy backlinks or use automated link networks.
- [ ] Do not mass-produce thin or copied articles.
- [ ] Use sources, authorship, corrections, and dates to make every page trustworthy.
- [ ] Prioritize specific Rajasthan employee queries before competing for broad national keywords.
